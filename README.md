# PaseoCompacto.com

Guía especializada en español para familias que buscan **coches de bebé compactos para viajar**, comparando modelos de **Ingenuity**, **Kolcraft**, **Doona** y referentes de cabina según **peso (`lb/kg`)**, **medidas al plegarse (`in/cm`)**, **facilidad para cerrarlos con una mano** y **espacio libre que dejan en la maletera para el equipaje**, junto con **bolsos de transporte**, **protectores de lluvia** y **organizadores compatibles** con enlaces de afiliado a Amazon Estados Unidos (`paseocompacto-20`) y Amazon España (`paseocompacto-21`).

- **Arquitectura SEO Anti-Canibalización**: 1,524 páginas editoriales (14 Hubs Pilares + 510 Artículos Transaccionales Amazon + 1,000 Artículos SEO Informacionales) + 8 páginas principales/legales = 1,532 rutas estáticas SSG.
- **Imágenes**: Fotorrealistas y visualmente diversas generadas con ChatGPT Image API (`quality: "medium"`) vía Supabase Edge Function `paseocompacto-images`, optimizadas en WebP por debajo de `100 KB`.
- **Asesor Online IA**: Edge Function `paseocompacto-chat` (`gpt-4o-mini` predeterminado) integrada con el panel administrador de `charlielingan.com`.
